# SEED B2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans under the owner's continuing native workflow. Canonical execution ledger: B2 section of `docs/seed-0.2-development-plan.md`.

**Goal:** Generate and preserve deterministic prospective predictions for the immediate same-transition post-action observation.

**Architecture:** A read-only `Predictor(memory).predict(state_before, action) -> Prediction` reads at most the latest 200 completed transitions. Three numeric targets use historical mean deltas; boolean network uses post-state frequency. Freeze the prediction into a plain JSON-compatible dictionary before action, emit it, then pass that same snapshot to the existing atomic experience write.

**Spec:** Owner's approved “SEED 0.2 — Batch B2: Environmental Predictor” instruction. **Tech stack:** standard library Python, existing SQLite schema v2, pytest.

## Constraints and design decisions

- Current checkout already has branch `seed-0.2-b2` at `845416c`, merged verified B1; preserve it. No merge, deployment, live database access, or B3+ work.
- Targets: battery_pct, load_ratio, disk_free_pct, network_reachable. The last reads the existing `network` observation key; no sensor renaming/probes.
- At least 2 valid samples per signal: action-specific → global → persistence. Window bounds raw recent rows, not 200 valid rows per target; malformed rows consume the bounded window and are skipped.
- Numeric values must be finite and valid (bool excluded). Battery/disk in 0..100; load >=0. Clamp predictions to physical lower/percentage upper bounds; preserve finite representability for extreme load sums.
- Network uses exact booleans in historical state-after, probability_true=count_true/n, True at a tie. Missing current targets are unavailable even when history exists.
- Confidence=min(.95,n/20), confidence_kind=evidence_support; persistence n=0/confidence=0. No accuracy/error calculations.
- Prediction payload has model=transition_delta_v1, model_version=1, horizon=next_post_action_observation, selected action, four signal records. No time/randomness in inference output.
- Existing B1 NULL predictions stay NULL; prediction_error_json stays NULL for all new B2 records. No migration.

## Review focus

Malformed/missing/nonfinite history must not stop inference; large finite arithmetic must serialize safely; history queries must stay bounded; current target cannot leak into prediction; prediction alone cannot write, sense, or network.
