## Design / interfaces

- semantic_v1 consumes only published B4 beliefs. Promotion n>=8 and confidence>=.30.
  Canonical structured numeric/Boolean payloads, source IDs/version/timestamps and
  first/last transition provenance; stable structural semantic key.
- Additive v5: semantic_memories, semantic_memory_history (complete prior row),
  consolidation_runs, consolidation_state singleton for bounded cyclic cursor.
- Each invocation reads at most100 beliefs, ascending from persistent cursor then
  wraps to lower IDs within remaining budget. This is a cyclic fairness cursor,
  not an ever-increasing exclusion watermark. Exact canonical source fingerprint
  detects material changes even with equal/reversed timestamps; timestamp-only
  updates do not revise semantics. All older IDs are eventually revisited.
- One semantic row per structural identity. Revision1 active creation; changed
  eligible statistics revise; loss of eligibility weakens without deletion;
  renewed support reactivates. Preserve previous full revision atomically.
- Malformed source: record bounded item failure, mark an existing semantic record
  source_unavailable without replacing its last valid stats, continue valid items.
  Missing sources reported by bounded read layer; no lifetime orphan sweep.
- Durable started run then one IMMEDIATE transaction for <=100 items, history,
  cursor, per-item events and final run statistics. Storage failures roll back that
  whole work transaction and record failed audit where possible, then propagate.
- Existing policy consolidate receives current pre-action observation explicitly;
  owner consolidate uses latest stored observation. Same engine, provenance,
  valid-resource guards; retain checkpoint metadata even when suppressed.
- No startup/wake/shutdown consolidation, new perception or curiosity trigger.
  All upstream algorithms and default-off B5 attention remain unchanged.
- Bounded read-only list/detail/history/run APIs. No deterministic prose needed;
  structured records are canonical.
